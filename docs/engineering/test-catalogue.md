## Database and integration tests

### 4.1 pgTAP (`supabase/tests/`)

| ID                              | Covers                                                                                                                                                                                                                                                                                                         |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| DB-RLS-all-tables-enabled       | RLS on for every `public` table                                                                                                                                                                                                                                                                                |
| DB-RLS-no-anon-writes           | `anon` cannot INSERT/UPDATE/DELETE anywhere                                                                                                                                                                                                                                                                    |
| DB-RLS-matrix                   | Table-driven impersonation of anon / customer A / customer B / builder A / builder B / builder C (inactive) / admin against the policy table in `07` §5 for S/I/U/D                                                                                                                                            |

| DB-FN-track_project_event       | 30/min limit; view de-dupe per hour (BR-71)                                                                                                                                                                                                                                                                    |
| DB-FN-rate_limit_hit            | Atomic under concurrency; window rollover; retry-after                                                                                                                                                                                                                                                         |
| DB-FN-search                    | `search_properties`: each filter alone and combined; sort stability; radius; bbox; label; keyword; only approved; explicit columns; `show` bounds                                                                                                                                                              |
| DB-FN-lifecycle RPCs            | `submit_listing`, `set_listing_status`, `moderate_listing`, `finalize_listing_media` (≤6, one cover)                                                                                                                                                                                                           |

| DB-STO-*                        | Storage policies per bucket (owner prefix, builder project prefix, admin-only `site-assets`, private `form-uploads`), bucket limits present                                                                                                                                                                    |

| DB-CASCADE                      | Delete rules: `project_leads` restrict (BR-44); cascades per model; enquiry `SET NULL` on user delete                                                                                                                                                                                                          |
| DB-AUDIT                        | Moderation, role, builder, CRM, CMS changes write `audit_log` with correct actor                                                                                                                                                                                                                               |

## Design-system validation

| Check                         | Method                                                                                                                                                                                   | Gate                                             |
| ----------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| Component variants and states | Design Lab renders every variant/state; registry test ensures every shared component has an entry                                                                                        | Fails unit test if missing                       |
| Accessibility (automated)     | axe on every Design Lab page and every E2E-visited state, WCAG 2.2 AA tags; no serious/critical                                                                                          | PR gate                                          |
| Accessibility (manual)        | Keyboard walk-through script per journey; screen reader pass (NVDA + Chrome/Firefox, VoiceOver iOS Safari) on search, detail, enquiry, wizard, dashboard, admin listings; recorded in S8 | S8 gate                                          |
| Contrast                      | `UT-tokens` computes ratios for every documented pair                                                                                                                                    | PR gate                                          |
| Responsive                    | Playwright projects at 390 / 820 / 1024 / 1280 / 1440; assertion `scrollWidth <= clientWidth`; screenshots on Design Lab and key screens                                                 | PR gate (subset), nightly (all)                  |
| Visual regression             | Baselines created from the first approved implementation; reviewed against `final-ux/renders/` by a human at S2 and for each new screen                                                  | PR gate; baseline updates need reviewer approval |
| Reduced motion                | Emulated `prefers-reduced-motion`: no animations, no carousel movement                                                                                                                   | Design Lab test                                  |
| Forced colours                | Spot check focus visibility in Windows high-contrast                                                                                                                                     | S8 manual                                        |

**Key screens with visual baselines (Chromium, three widths):** `home-a` (1 sponsor, 3 sponsors, near-miss), `home-b` (same), `home-none`, `search` (results, empty, loading, error, filter sheet), `property` (signed out, signed in, errors, sheet), `project`, `compare`, `auth` (phone, OTP, errors), `dashboard` (each tab), `post-property` (each step, errors), `admin-overview`, `admin-listings`, `admin-projects`, `builder-dashboard`, `errors`.
