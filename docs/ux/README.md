# Approved UX reference (read-only)

A copy of the approved UX package (`final-ux`) and the UX addendum (`ux-addendum`): documents, HTML prototypes, CSS and the small render tools. The 56 MB of rendered images are **not** copied. Open `final-ux/index.html` and `ux-addendum/index.html` in a browser for the prototypes (thumbnails in the galleries will be blank); regenerate images with the packages' own `tools/render.mjs` (needs Chrome or Edge), or use the original UX repositories.

Rules: do not edit these files; a design change is a pull request that updates the UX package at its source and this copy together, approved by the owner (R-DS-05, R-DS-06). Screen keys, routes and states are indexed in `docs/ux-reference.md`. The token snapshot for the parity check is `final-ux/assets/tokens.css`.
