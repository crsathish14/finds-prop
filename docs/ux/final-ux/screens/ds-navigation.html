Design system

Navigation

One public header for everyone, a role-aware account menu, and one portal shell for admin and builder. Navigation only reflects roles and permissions that exist in Phase 1; agent navigation is shown as a proposal.

Principle

ConsistentThe main navigation never changes with role. Roles add one entry to the account menu and, inside /admin and /builder, swap the public header for the portal shell.
HonestNothing appears that the person cannot use. A signed-out visitor who taps Saved or Post property is sent to sign-in and returned afterwards.
AvoidedNo role switcher, no separate “agent” header, no admin links in the public header.

Portal shell

Admin and builder

Admin grouped: Moderation · Inventory · Leads and CRM · Site content
Builder one flat list of six
Desktop ≥ 1100 px256 px forest sidebar, sticky, with group labels, counts and “View public site”. The current page has a lighter fill and a copper marker on the left edge.
Tablet 768 to 1099 pxThe sidebar collapses to a 76 px icon rail. Labels become tooltips; counts become small dots. See any portal screen rendered at 820 px.
Mobile < 768 pxThe sidebar becomes a left drawer opened from the menu button in the top bar. Tables become stacked cards, forms stay single column.
