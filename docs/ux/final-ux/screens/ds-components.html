Design system

Components

Each component is defined once (assets/c-*.css, assets/js/fp-ui.js) and used everywhere. The same component never changes look or behaviour between unrelated screens; where portals use denser sizes it is a documented size, not a new component.

Actions

Buttons

Copper is the single conversion action on a public screen (Search, Send enquiry, Submit listing, Sign in). Forest is the primary action in portals and for secondary navigation actions. Never two copper buttons in one view.
